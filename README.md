# 焰场 · GitHub Pages 静态站点

岸边、扁舟、夜航，三套沉浸烟花主题，包含独立音乐、实时烟花与动态环境。

## 发布

这是无需构建、无需后端的纯静态网站。将本目录内的文件上传到 GitHub 仓库的根目录（保留 `assets` 文件夹和 `.nojekyll`），然后在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支 `main`，目录 `/(root)`，保存。

项目站点地址一般为 `https://你的用户名.github.io/everglow-fireworks/`。所有站内资源均使用相对路径，可从该子路径访问。具体公开地址以 Pages 设置页显示为准。

## 使用

首次点击进入以开启声音；手机可尝试进入全屏横屏。浏览器、音频权限和设备性能会影响体验。
